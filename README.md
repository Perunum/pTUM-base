# pTUM-base
Functional base for neural distribution models, covering categorical, continuous, and time-to-event distributions including competing risks. It forms a lightweight, complete stochastic framework for actuaries. Assumption-free credibility using sigma-hot encoding & weight balancing is built in.

Presented twice at the Insurance Data Science Conference, in Stockholm (2024) and London (2025). See also the repositories for sigma-hot-encoding and claim-interarrival-times.
